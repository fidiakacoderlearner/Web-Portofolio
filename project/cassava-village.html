Cassava Village

Website LKPD interaktif bertema Desa Singkong untuk materi komposisi fungsi (Fase F).

Tentang Project

Cassava Village adalah Lembar Kerja Peserta Didik (LKPD) interaktif yang membawa siswa belajar komposisi fungsi melalui alur cerita Pak Restu dan Pak Rafif. Siswa mengeksplorasi materi, mengerjakan kuis, dan jawabannya tersimpan secara otomatis sehingga guru dapat memantau perkembangan belajar mereka.

Aplikasi dibagi menjadi dua bagian: client (React) untuk tampilan siswa & guru, dan server (Express + PostgreSQL) sebagai API dan penyimpanan data.

Fitur Utama

  • Alur cerita interaktif bersama Pak Restu & Pak Rafif
  • Eksplorasi materi komposisi fungsi (Fase F)
  • Kuis / evaluasi interaktif
  • Penyimpanan jawaban siswa secara otomatis
  • Dashboard guru untuk memantau hasil belajar siswa
  • Autentikasi guru & siswa dengan kode kelas

Teknologi

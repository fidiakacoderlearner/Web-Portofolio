Mathbiz Riau

Permainan edukasi berbasis web yang menggabungkan matematika, kewirausahaan, dan budaya Melayu Riau.

Tentang Project

Mathbiz Riau adalah permainan edukasi berbasis web (Single Page Application) di mana pemain membangun usaha virtual — mulai dari perencanaan bisnis, produksi, hingga penjualan — sambil menyelesaikan tantangan matematika yang terintegrasi ke dalam mekanisme permainan.

Seluruh data permainan (XP, budget, riwayat, progres produk, status karyawan) disimpan secara lokal menggunakan React Context API dan Local Storage, sehingga arsitektur tetap ringan dan tidak memerlukan autentikasi maupun konfigurasi server.

Fitur Utama

  • Simulasi bisnis interaktif berbasis cerita
  • Sistem XP dan progres pemain
  • Manajemen budget dan sumber daya
  • Sistem perekrutan karyawan dengan inflasi biaya
  • Solver program linear untuk optimasi keuntungan
  • Generasi soal pertidaksamaan secara dinamis
  • Visualisasi grafik menggunakan SVG native
  • Penyimpanan progres otomatis via Local Storage
  • Desain antarmuka bernuansa budaya Melayu Riau

Komponen Edukasi

  • Sistem pertidaksamaan linear
  • Program linear
  • Analisis titik optimum
  • Perhitungan biaya produksi & keuntungan
  • Pengelolaan sumber daya usaha

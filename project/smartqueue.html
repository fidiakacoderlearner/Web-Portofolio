SmartQueue

Aplikasi desktop berbasis JavaFX untuk mengelola sistem antrian asistensi secara real-time.

Jenis
Aplikasi desktop
Peran
Tugas kelompok — PBO
Stack
Java 21 / JavaFX 21 / Maven / Firebase / Gson / BootstrapFX

Tentang project

SmartQueue adalah aplikasi desktop yang membantu pengelolaan antrian asistensi di lingkungan perkuliahan. Mahasiswa dapat mengambil nomor antrian dan memantau posisinya secara langsung, sementara asisten dapat mengatur antrian, membuka atau menutup layanan, serta mengelola slot asistensi kelompok.

Seluruh data antrian dan informasi asistensi disinkronisasi secara real-time melalui Firebase Realtime Database, sehingga status antrian selalu terbaru di setiap perangkat. Aplikasi dibangun dengan menerapkan konsep Pemrograman Berbasis Objek (OOP) seperti encapsulation, inheritance, polymorphism, dan abstraction.

Project ini merupakan tugas kelompok mata kuliah Pemrograman Berbasis Objek (PBO) Semester 3, Program Studi Teknik Informatika, Universitas Riau.

Fitur utama

  • Pemilihan akses sebagai mahasiswa atau asisten
  • Sistem antrian real-time (menunggu, sedang dilayani, riwayat)
  • Login dan registrasi akun mahasiswa
  • Panel asisten untuk mengelola antrian & informasi asistensi
  • Pengaturan estimasi waktu tunggu dan buka/tutup antrian
  • Kelola data mahasiswa oleh asisten
  • Sistem chat antara mahasiswa dan asisten
  • Manajemen slot asistensi kelompok
  • Pengaturan pertanyaan keamanan (recovery question)
  • Sinkronisasi data terpusat lewat Firebase Realtime Database

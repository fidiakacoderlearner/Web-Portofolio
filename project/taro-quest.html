Taro Quest

Website LKPD interaktif bertema Desa Talas untuk materi komposisi fungsi, dengan antarmuka dua bahasa.

Jenis
LKPD dua bahasa
Peran
Tim teaMate — client & server
Stack
React 19 / Vite 7 / Tailwind CSS 4 / Express / PostgreSQL / JWT

Tentang project

Taro Quest adalah Lembar Kerja Peserta Didik (LKPD) interaktif yang mengajak siswa mempelajari komposisi fungsi melalui kisah petualangan di Desa Talas bersama Bu Aza dan Bu Zia. Materi disampaikan lewat alur cerita, eksplorasi terbimbing, eksperimen drag & drop, hingga kuis evaluasi.

Jawaban siswa tersimpan di server sehingga guru dapat memantau perkembangan belajar tiap siswa dan mengelola kelas melalui dashboard. Aplikasi ini berskala internasional: antarmukanya tersedia dalam dua bahasa (Inggris & Indonesia) sehingga tidak terikat pada kurikulum nasional tertentu.

Aplikasi dibagi menjadi dua bagian: client (React 19 + Vite) untuk tampilan siswa & guru, dan server (Express + PostgreSQL) sebagai API dan penyimpanan data. Dikembangkan oleh tim teaMate — Alya Diandra Febry Dalimunthe & Afdhal Fidi Ansori (Universitas Riau).

Fitur utama

  • Alur cerita interaktif di Desa Talas bersama Bu Aza & Bu Zia
  • Eksplorasi materi komposisi fungsi (24 langkah)
  • Eksperimen drag & drop dan kuis evaluasi interaktif
  • Penyimpanan jawaban siswa secara otomatis
  • Dashboard guru untuk memantau progres siswa
  • Manajemen kelas dengan kode kelas (buat, gabung, keluarkan siswa)
  • Autentikasi JWT dan role guru / siswa
  • Antarmuka dua bahasa (Inggris & Indonesia)
  • Pengujian E2E dengan Playwright
